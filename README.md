# Dachshund

A Fabric mod for Minecraft 26.3 that adds a loyal, indestructible dachshund companion.

Download it on [Modrinth](https://modrinth.com/mod/dachshund-mnjongen).

## Features

- Craft a **Dachshund Whistle** (iron nugget, bone, iron nugget) and use it to spawn a tamed dachshund
- The dachshund follows you, sits when told, can be fed bones and can't be hurt
- Creepers avoid dachshunds, just like cats
- Dachshund-themed title screen splash texts

## Building

Requires Java 25.

```
./gradlew build
```

The mod jar ends up in `build/libs/`. To start a test client, run `./gradlew runClient`.
